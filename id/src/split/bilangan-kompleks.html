36 Bilangan Kompleks

Primer singkat tentang bilangan kompleks184 yang dicuri langsung dari Wikipedia:

A complex number is a number that can be expressed in the form \(a+bi\), where \(a\) and \(b\) are real numbers [i.e. floating point types in C], and \(i\) represents the imaginary unit, satisfying the equation \(i^2=−1\). Because no real number satisfies this equation, \(i\) is called an imaginary number. For the complex number \(a+bi\), \(a\) is called the real part, and \(b\) is called the imaginary part.

Tapi hanya sampai di situ yang akan kujelaskan. Kita anggap kalau kamu membaca bab ini, kamu sudah tahu apa itu bilangan kompleks dan apa yang ingin kamu lakukan dengannya.

Yang perlu kita bahas hanyalah kemampuan C untuk itu.

Ternyata, dukungan bilangan kompleks di compiler adalah fitur opsional. Tidak semua compiler yang patuh standar bisa melakukannya. Dan yang bisa pun mungkin mendukungnya dengan tingkat kelengkapan yang berbeda-beda.

Kamu bisa menguji apakah sistemmu mendukung bilangan kompleks dengan:

#ifdef __STDC_NO_COMPLEX__
#error Complex numbers not supported!
#endif

Selain itu, ada makro yang menandakan kepatuhan pada standar ISO 60559 (IEEE 754) untuk matematika floating point dengan bilangan kompleks, serta adanya tipe _Imaginary.

#if __STDC_IEC_559_COMPLEX__ != 1
#error Need IEC 60559 complex support!
#endif

Detail lebih lanjut dijabarkan di Annex G spesifikasi C11.

36.1 Tipe Kompleks

Untuk memakai bilangan kompleks, #include <complex.h>.

Dengan itu, kamu mendapat setidaknya dua tipe:

_Complex
complex

Keduanya berarti sama, jadi sebaiknya pakai complex yang lebih cantik.

Kamu juga mendapat beberapa tipe untuk bilangan imajiner kalau implementasimu patuh IEC 60559:

_Imaginary
imaginary

Ini juga keduanya berarti sama, jadi sebaiknya pakai imaginary yang lebih cantik.

Kamu juga mendapat nilai untuk bilangan imajiner \(i\) itu sendiri:

I
_Complex_I
_Imaginary_I

Makro I diatur menjadi _Imaginary_I (kalau tersedia), atau _Complex_I. Jadi pakai saja I untuk bilangan imajiner.

Satu catatan sampingan: tadi kubilang bahwa kalau compiler punya __STDC_IEC_559_COMPLEX__ bernilai 1, ia harus mendukung tipe _Imaginary agar patuh. Itu bacaanku atas spesifikasi. Namun, aku tidak tahu satu pun compiler yang benar-benar mendukung _Imaginary meskipun __STDC_IEC_559_COMPLEX__-nya diatur. Jadi aku akan menulis sebagian kode dengan tipe itu di sini tanpa bisa mengujinya. Maaf!

Oke, sekarang kita tahu ada tipe complex, bagaimana cara memakainya?

36.2 Menugaskan Bilangan Kompleks

Karena bilangan kompleks punya bagian real dan imajiner, dan keduanya bergantung pada bilangan floating point untuk menyimpan nilai, kita juga perlu memberi tahu C presisi apa yang dipakai untuk bagian-bagian bilangan kompleks itu.

Caranya, tinggal menyematkan float, double, atau long double pada complex, baik sebelum maupun sesudahnya.

Mari kita definisikan bilangan kompleks yang memakai float untuk komponennya:

float complex c;   // Spesifikasi lebih suka cara ini
complex float c;   // Sama saja--urutan tidak berpengaruh

Itu bagus untuk deklarasi, tapi bagaimana cara menginisialisasi atau menugaskannya?

Ternyata kita bisa memakai notasi yang cukup alami. Contoh!

double complex x = 5 + 2*I;
double complex y = 10 + 3*I;

Masing-masing untuk \(5+2i\) dan \(10+3i\).

36.3 Membentuk, Membongkar, dan Mencetak

Kita hampir sampai…

Kita sudah melihat satu cara menulis bilangan kompleks:

double complex x = 5 + 2*I;

Tidak masalah juga memakai bilangan floating point lain untuk membentuknya:

double a = 5;
double b = 2;
double complex x = a + b*I;

Ada juga sekumpulan makro untuk membantu membentuknya. Kode di atas bisa ditulis memakai makro CMPLX(), seperti ini:

double complex x = CMPLX(5, 2);

Sejauh yang kutemukan dalam risetku, keduanya hampir setara:

double complex x = 5 + 2*I;
double complex x = CMPLX(5, 2);

Tapi makro CMPLX() akan selalu menangani nol negatif pada bagian imajiner dengan benar, sedangkan cara yang lain mungkin mengonversinya menjadi nol positif. Aku kira185 ini menyiratkan bahwa kalau ada kemungkinan bagian imajinernya nol, sebaiknya pakai makro… tapi seseorang tolong koreksi kalau aku keliru!

Makro CMPLX() bekerja pada tipe double. Ada dua makro lain untuk float dan long double: CMPLXF() dan CMPLXL(). (Sufiks “f” dan “l” ini muncul di hampir semua fungsi terkait bilangan kompleks.)

Sekarang kita coba kebalikannya: kalau kita punya bilangan kompleks, bagaimana memecahnya menjadi bagian real dan imajinernya?

Ada beberapa fungsi yang mengambil bagian real dan imajiner dari angka itu: creal() dan cimag():

double complex x = 5 + 2*I;
double complex y = 10 + 3*I;

printf("x = %f + %fi\n", creal(x), cimag(x));
printf("y = %f + %fi\n", creal(y), cimag(y));

dengan output:

x = 5.000000 + 2.000000i
y = 10.000000 + 3.000000i

Perhatikan bahwa i yang kupakai pada format string printf() adalah i literal yang dicetak—ia bukan bagian dari format specifier. Kedua nilai kembalian creal() dan cimag() bertipe double.

Dan seperti biasa, ada varian float dan long double dari fungsi-fungsi ini: crealf(), cimagf(), creall(), dan cimagl().

36.4 Aritmetika dan Perbandingan Kompleks

Aritmetika bisa dilakukan pada bilangan kompleks, walaupun cara kerjanya secara matematis di luar cakupan panduan ini.

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex x = 1 + 2*I;
    double complex y = 3 + 4*I;
    double complex z;

    z = x + y;
    printf("x + y = %f + %fi\n", creal(z), cimag(z));

    z = x - y;
    printf("x - y = %f + %fi\n", creal(z), cimag(z));

    z = x * y;
    printf("x * y = %f + %fi\n", creal(z), cimag(z));

    z = x / y;
    printf("x / y = %f + %fi\n", creal(z), cimag(z));
}

dengan hasil:

x + y = 4.000000 + 6.000000i
x - y = -2.000000 + -2.000000i
x * y = -5.000000 + 10.000000i
x / y = 0.440000 + 0.080000i

Kamu juga bisa membandingkan dua bilangan kompleks untuk kesamaan (atau ketidaksamaan):

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex x = 1 + 2*I;
    double complex y = 3 + 4*I;

    printf("x == y = %d\n", x == y);  // 0
    printf("x != y = %d\n", x != y);  // 1
}

dengan output:

x == y = 0
x != y = 1

Keduanya sama kalau kedua komponennya sama. Perhatikan bahwa seperti pada semua floating point, keduanya bisa dianggap sama kalau cukup dekat karena galat pembulatan186.
