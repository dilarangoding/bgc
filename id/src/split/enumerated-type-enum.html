22 Enumerated Type: enum

C menawarkan cara lain untuk memiliki nilai integer konstan dengan nama: enum.

Misalnya:

enum {
  ONE=1,
  TWO=2
};

printf("%d %d", ONE, TWO);  // 1 2

Dalam beberapa hal, ini bisa lebih baik—atau berbeda—dibanding memakai #define. Perbedaan utamanya:

  • enum hanya bisa berupa tipe integer.
  • #define bisa mendefinisikan apa saja.
  • enum sering ditampilkan dengan nama identifier simbolisnya di debugger.
  • Angka hasil #define hanya tampil sebagai angka mentah yang lebih sulit diketahui maknanya saat debugging.

Karena berupa tipe integer, mereka bisa dipakai di tempat mana pun integer bisa dipakai, termasuk pada dimensi array dan pernyataan case.

Mari kita bedah lebih jauh.

22.1 Perilaku enum

22.1.1 Penomoran

enum diberi nomor otomatis kecuali kamu menimpanya.

Penomoran dimulai dari 0, dan bertambah otomatis dari sana, secara bawaan:

enum {
    SHEEP,  // Nilainya 0
    WHEAT,  // Nilainya 1
    WOOD,   // Nilainya 2
    BRICK,  // Nilainya 3
    ORE     // Nilainya 4
};

printf("%d %d\n", SHEEP, BRICK);  // 0 3

Kamu bisa memaksakan nilai integer tertentu, seperti yang sudah kita lihat tadi:

enum {
  X=2,
  Y=18,
  Z=-2
};

Duplikat tidak masalah:

enum {
  X=2,
  Y=2,
  Z=2
};

kalau nilai dihilangkan, penomoran melanjutkan hitungan ke arah positif dari nilai yang terakhir ditentukan. Misalnya:

enum {
  A,    // 0, nilai awal bawaan
  B,    // 1
  C=4,  // 4, diatur manual
  D,    // 5
  E,    // 6
  F=3,  // 3, diatur manual
  G,    // 4
  H     // 5
}

22.1.2 Koma di Akhir

Ini sepenuhnya boleh, kalau itu gayamu:

enum {
  X=2,
  Y=18,
  Z=-2,   // <-- Koma di akhir
};

Gaya ini makin populer di bahasa-bahasa dekade terakhir, jadi kamu mungkin senang melihatnya.

22.1.3 Scope

enum mengikuti scope seperti yang kamu harapkan. Kalau di file scope, seluruh file bisa melihatnya. Kalau di dalam blok, ia lokal untuk blok itu.

Sangat umum enum didefinisikan di header file sehingga bisa di-#include di file scope.

22.1.4 Gaya Penulisan

Seperti yang kamu perhatikan, umumnya simbol enum dideklarasikan dengan huruf besar (dengan underscore).

Ini bukan keharusan, tapi merupakan idiom yang sangat, sangat umum.

22.2 enum-mu adalah Sebuah Tipe

Ini hal penting yang perlu diketahui tentang enum: ia adalah sebuah tipe, seperti halnya struct adalah sebuah tipe.

Kamu bisa memberinya nama tag sehingga bisa merujuk ke tipe itu nanti dan mendeklarasikan variabel bertipe itu.

Nah, karena enum adalah tipe integer, kenapa tidak pakai int saja?

Di C, alasan terbaiknya adalah kejelasan kode–ini cara bertipe yang rapi untuk menjelaskan pemikiranmu dalam kode. C (tidak seperti C++) sebenarnya tidak memaksa nilai apa pun berada dalam rentang untuk enum tertentu.

Mari kita coba contoh ketika kita mendeklarasikan variabel r bertipe enum resource yang bisa menampung nilai-nilai itu:

// enum bernama, tipenya "enum resource"

enum resource {
    SHEEP,
    WHEAT,
    WOOD,
    BRICK,
    ORE
};

// Deklarasikan variabel "r" bertipe "enum resource"

enum resource r = BRICK;

if (r == BRICK) {
    printf("I'll trade you a brick for two sheep.\n");
}

Kamu juga bisa me-typedef-nya, tentu saja, walaupun secara pribadi aku tidak suka.

typedef enum {
    SHEEP,
    WHEAT,
    WOOD,
    BRICK,
    ORE
} RESOURCE;

RESOURCE r = BRICK;

Jalan pintas lain yang legal tapi jarang adalah mendeklarasikan variabel saat mendeklarasikan enum:

// Deklarasikan enum dan beberapa variabel terinisialisasi bertipe itu:

enum {
    SHEEP,
    WHEAT,
    WOOD,
    BRICK,
    ORE
} r = BRICK, s = WOOD;

Kamu juga bisa memberi nama pada enum agar bisa dipakai nanti, yang mungkin ingin kamu lakukan pada kebanyakan kasus:

// Deklarasikan enum dan beberapa variabel terinisialisasi bertipe itu:

enum resource {   // <-- tipenya sekarang "enum resource"
    SHEEP,
    WHEAT,
    WOOD,
    BRICK,
    ORE
} r = BRICK, s = WOOD;

Singkatnya, enum adalah cara yang bagus untuk menulis kode yang rapi, ber-scope, dan bertipe.
