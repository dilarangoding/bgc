7 Strings

Akhirnya! Strings! Apa yang bisa lebih sederhana dari ini?

Nah, ternyata string di C sebenarnya bukan string. Betul! Mereka itu pointer! Tentu saja mereka pointer!

Seperti array, string di C nyaris tidak ada.

Tapi kita lihat saja—sebenarnya tidak seseram itu.

7.1 String Literal

Sebelum mulai, mari kita bahas dulu string literal di C. String literal berupa deretan karakter di dalam tanda kutip ganda ("). (Tanda kutip tunggal mengapit karakter, dan itu makhluk yang sama sekali berbeda.)

Contoh:

"Hello, world!\n"
"This is a test."
"When asked if this string had quotes in it, she replied, \"It does.\""

Yang pertama punya newline di ujungnya—pemandangan yang sangat umum.

Yang terakhir punya tanda kutip di dalamnya, dan kamu bisa lihat masing-masing didahului (kita bilang “di-escape oleh”) sebuah backslash (\) yang menandakan bahwa di titik itu ada tanda kutip literal yang menjadi bagian string. Begitulah cara C compiler membedakan antara mencetak tanda kutip ganda dan tanda kutip ganda penutup string.

7.2 Variabel String

Setelah tahu cara membuat string literal, sekarang kita tugaskan ke sebuah variabel supaya bisa kita pakai.

char *s = "Hello, world!";

Perhatikan tipenya: pointer ke char. Variabel string s sebenarnya adalah pointer ke karakter pertama string itu, yaitu H.

Kita bisa mencetaknya dengan format specifier %s (untuk “string”):

char *s = "Hello, world!";

printf("%s\n", s);  // "Hello, world!"

7.3 Variabel String sebagai Array

Pilihan lainnya adalah ini, yang hampir setara dengan pemakaian char* di atas:

char s[14] = "Hello, world!";

// atau, kalau kita malas dengan benar dan menyuruh compiler
// menghitung panjangnya untuk kita:

char s[] = "Hello, world!";

Artinya, kamu bisa memakai notasi array untuk mengakses karakter dalam string. Mari kita lakukan persis itu untuk mencetak semua karakter string dalam satu baris:

#include <stdio.h>

int main(void)
{
    char s[] = "Hello, world!";

    for (int i = 0; i < 13; i++)
        printf("%c", s[i]);
    printf("\n");
}

Perhatikan bahwa kita memakai format specifier %c untuk mencetak satu karakter.

Lihat juga ini. Programnya tetap berjalan dengan baik kalau definisi s kita ubah menjadi tipe char*:

#include <stdio.h>

int main(void)
{
    char *s = "Hello, world!";   // char* di sini

    for (int i = 0; i < 13; i++)
        printf("%c", s[i]);    // Tapi masih memakai array di sini...?
    printf("\n");
}

Dan kita masih bisa memakai notasi array untuk mencetaknya! Ini mengejutkan, tapi itu hanya karena kita belum membahas kesetaraan array/pointer. Meski begitu, ini satu petunjuk lagi bahwa array dan pointer itu sama saja, jauh di dalamnya.

7.4 Inisialisasi String

Kita sudah melihat beberapa contoh inisialisasi variabel string dengan string literal:

char *s = "Hello, world!";
char t[] = "Hello, again!";

Tapi kedua inisialisasi ini berbeda secara halus. Sebuah string literal, seperti integer literal, memorinya dikelola otomatis oleh compiler untukmu! Untuk integer, yaitu data berukuran tetap, compiler bisa mengelolanya dengan mudah. Tapi string adalah makhluk berukuran byte yang bervariasi, yang dijinakkan compiler dengan cara dilempar ke sepotong memori, lalu kamu diberi pointer ke sana.

Bentuk ini menunjuk ke mana pun string itu ditaruh. Biasanya tempat itu berada di negeri yang jauh dari memori program lainnya – yaitu memori read-only – karena alasan performa dan keamanan.

char *s = "Hello, world!";

Jadi, kalau kamu mencoba mengubah string itu dengan ini:

char *s = "Hello, world!";

s[0] = 'z';  // KABAR BURUK: mencoba mengubah string literal!

Perilakunya undefined. Tergantung sistemmu, kemungkinan besar hasilnya crash.

Tapi mendeklarasikannya sebagai array itu berbeda. Compiler tidak menyembunyikan byte-byte itu di bagian kota yang lain; mereka ada di jalan seberang rumahmu. Yang satu ini salinan string yang bisa diubah – bisa kita ubah sesuka hati:

char t[] = "Hello, again!";  // t adalah salinan array dari string itu
t[0] = 'z'; //  Tidak masalah

printf("%s\n", t);  // "zello, again!"

Jadi ingat: kalau kamu punya pointer ke string literal, jangan coba mengubahnya! Dan kalau kamu memakai string di dalam tanda kutip ganda untuk menginisialisasi array, itu sebenarnya bukan string literal.

7.5 Mendapatkan Panjang String

Tidak bisa, karena C tidak mencatatnya untukmu. Dan kalau dibilang “tidak bisa”, maksudnya sebenarnya “bisa”63. Ada fungsi di <string.h> bernama strlen() yang bisa dipakai untuk menghitung panjang string apa pun dalam byte64.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char *s = "Hello, world!";

    printf("The string is %zu bytes long.\n", strlen(s));
}

Fungsi strlen() mengembalikan tipe size_t, yaitu tipe integer sehingga bisa dipakai untuk perhitungan integer. Kita mencetak size_t dengan %zu.

Program di atas mencetak:

The string is 13 bytes long.

Bagus! Jadi ternyata bisa mendapatkan panjang string!

Tapi… kalau C tidak mencatat panjang string di mana pun, bagaimana ia tahu seberapa panjang string itu?

7.6 Terminasi String

C memperlakukan string sedikit berbeda dari banyak bahasa pemrograman, dan sebenarnya berbeda dari hampir semua bahasa pemrograman modern.

Saat membuat bahasa baru, pada dasarnya ada dua pilihan untuk menyimpan string di memori:

  1. Simpan byte-byte string beserta sebuah angka yang menyatakan panjang string.

  2. Simpan byte-byte string, dan tandai akhir string dengan byte khusus yang disebut terminator.

Kalau kamu ingin string yang lebih panjang dari 255 karakter, pilihan 1 membutuhkan setidaknya dua byte untuk menyimpan panjangnya. Sedangkan pilihan 2 hanya butuh satu byte untuk mengakhiri string. Jadi ada sedikit penghematan di sana.

Tentu saja, zaman sekarang menghemat satu byte (atau 3—banyak bahasa dengan senang hati membolehkan string sepanjang 4 gigabyte) terasa konyol. Tapi dulu, itu urusan yang lebih besar.

Jadi C memilih pendekatan #2. Di C, sebuah “string” didefinisikan oleh dua ciri dasar:

  • Sebuah pointer ke karakter pertama string.
  • Sebuah byte bernilai nol (atau karakter NUL65) di suatu tempat di memori setelah pointer itu, yang menandai akhir string.

Karakter NUL bisa ditulis di kode C sebagai \0, meski jarang kamu perlu melakukannya.

Ketika kamu menulis string di dalam tanda kutip ganda di kodemu, karakter NUL otomatis dan implisit ikut disertakan.

char *s = "Hello!";  // Sebenarnya "Hello!\0" di balik layar

Dengan ini, mari kita tulis fungsi strlen() kita sendiri yang menghitung char dalam string sampai menemukan NUL.

Caranya, telusuri string untuk mencari satu karakter NUL, sambil menghitung66:

int my_strlen(char *s)
{
    int count = 0;

    while (s[count] != '\0')  // Tanda kutip tunggal untuk satu karakter
        count++;

    return count;
}

Dan pada dasarnya begitulah cara strlen() bawaan menyelesaikan tugasnya.

7.7 Menyalin String

String tidak bisa disalin lewat operator penugasan (=). Yang terjadi hanyalah menyalin pointer ke karakter pertama… sehingga akhirnya kamu punya dua pointer ke string yang sama:

#include <stdio.h>

int main(void)
{
    char s[] = "Hello, world!";
    char *t;

    // Ini menyalin pointer-nya, bukan menyalin string-nya!
    t = s;

    // Kita ubah t
    t[0] = 'z';

    // Tapi mencetak s menampilkan perubahannya!
    // Karena t dan s menunjuk ke string yang sama!

    printf("%s\n", s);  // "zello, world!"
}

Kalau kamu ingin menyalin string, kamu harus menyalinnya byte demi byte—artinya kamu mengambil byte-byte string dari satu tempat di memori dan menduplikasinya ke tempat lain di memori. Ini dipermudah oleh fungsi strcpy().67

Sebelum menyalin string, pastikan ada ruang untuk menampung salinannya, yaitu array tujuan yang akan menampung karakter-karakternya harus setidaknya sepanjang string yang disalin.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "Hello, world!";
    char t[100];  // Setiap char satu byte, jadi ruangnya lebih dari cukup

    // Ini menyalin string-nya!
    strcpy(t, s);

    // Kita ubah t
    t[0] = 'z';

    // Dan s tidak terpengaruh karena itu string yang berbeda
    printf("%s\n", s);  // "Hello, world!"

    // Tapi t sudah berubah
    printf("%s\n", t);  // "zello, world!"
}

Perhatikan bahwa pada strcpy(), pointer tujuan adalah argumen pertama, dan pointer sumber adalah argumen kedua. Trik untuk mengingatnya: ini urutan yang akan kamu pakai untuk menulis t dan s seandainya penugasan = bekerja untuk string, dengan sumber di kanan dan tujuan di kiri.
